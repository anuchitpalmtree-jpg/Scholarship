# Grant+ ทุนที่ใช่ ไปได้ไกลกว่า

Grant+ เป็น business-app prototype สำหรับค้นหาทุนวิจัย ตรวจความครบของข้อเสนอ กรอกและบันทึกใบสมัคร และทดลองติดตามกระบวนการพิจารณาของแต่ละแหล่งทุน โดยรองรับกรณีผู้ประสานงานลงทะเบียนแทนนักวิจัย

## Current Scope

- หน้า public แสดงตัวอย่างทุนที่เปิดรับแบบภาพเลื่อน พร้อมรายละเอียด ลิงก์ต้นทาง และจำนวนผู้สมัครจำลอง
- Mock Google/government sign-in ที่แยก “ผู้วิจัย” ออกจาก “ผู้ลงทะเบียน”
- เลือกได้ระหว่าง Simulation mode และโหมดกรอก/บันทึกข้อมูลจริงในเบราว์เซอร์
- AI Smart Match และแบบฟอร์มที่เติมข้อมูลสาธิต
- Readiness check ที่ตรวจเฉพาะหัวข้อและเอกสารตามแม่แบบของ วช., NIA และ บพข.
- Semantic Checker แบบแจ้งเตือนและให้ผู้สมัครยืนยันไปต่อ
- ตารางติดตามวันที่กองทุนรับเรื่อง รหัสรับเรื่อง และตัวอย่างอีเมลเมื่อสถานะเปลี่ยน
- เส้นทางจำลอง 6 ขั้นตอน ตั้งแต่บันทึกข้อมูล ส่งต่อ ตรวจเอกสาร ผู้ทรงคุณวุฒิ คณะกรรมการ จนถึงประกาศผล

## Useful Commands

```bash
npm install
npm run dev
npm run build
npm test
```

## Demo Notes

Simulation mode ใช้ข้อมูลตัวอย่างและไม่บันทึกถาวร ส่วนโหมดกรอกข้อมูลบันทึกร่างและรายการใบสมัครใน `localStorage` ของเบราว์เซอร์เครื่องนั้นเท่านั้น ภาพประกอบใน `public/grants` สร้างขึ้นสำหรับ prototype นี้ จำนวนผู้สมัครและช่วงเวลาที่ระบุว่าเป็นตัวอย่างไม่ใช่ข้อมูลสด ระบบยังไม่เชื่อม Google OAuth, ฐานข้อมูลร่วม, ที่เก็บไฟล์, หน่วยงานให้ทุน หรือบริการส่งอีเมลจริง
