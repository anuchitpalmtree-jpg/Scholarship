## ฐานงบที่ต้องพูดให้ตรงกัน

กรอบเดิม 56.1 ล้านบาทใน 3 ปี และต้นทุน 5 ปี 82.1 ล้านบาท ยังเป็นประมาณการก่อนทบทวนขอบเขตใหม่ ปีแรก 33.6 ล้านบาทเป็นงบรวมทุกหมวด ค่าเชื่อม/แลกเปลี่ยนข้อมูลในแบบจำลองเดิมคือ 7 ล้านบาทปีแรก และ 12.5 ล้านบาทรวมสามปี ไม่ควรนำข้อสรุปว่า API 33 ล้านบาทไปใช้เป็นรายการต้นทุนที่ตรวจแล้ว

SROI เดิม 0.64 / 12.29 / 5.07 เป็นสถานการณ์คาดการณ์จากสมมติฐานเดิม ต้องทบทวนปริมาณใบสมัครและช่วงเวลาต้นทุน ไม่ใช่ผลนำร่องหรือผลหลังเพิ่มโมดูลใหม่ ส่วนต่างต้นทุนในหน้าย่อย /admin/costs เป็นเพียงการคำนวณตามค่าที่ป้อน
