# Grant+ Operating Details

## Records

| รายการ | ข้อมูลที่แสดงใน prototype |
| --- | --- |
| Identity context | บทบาท ชื่อ/อีเมลผู้ลงทะเบียน ชื่อ/อีเมลผู้วิจัย และหน่วยงาน |
| Public grant | ชื่อทุน หน่วยงาน สรุป ช่วงเปิดรับ จำนวนผู้สมัครจำลอง ภาพประกอบ tag และลิงก์ต้นทาง |
| Fund template | แหล่งทุน รุ่นแม่แบบ URL ต้นทาง และหัวข้อที่ต้องมีพร้อมสถานะครบ/บางส่วน/ไม่พบ |
| Remembered session | hash ของ token, ผู้ใช้, วันสร้าง และวันหมดอายุ; token จริงอยู่ใน cookie เท่านั้น |
| Application | โครงการ แหล่งทุน วันบันทึก/ส่ง รหัสรับเรื่องจำลอง ขั้นตอนจำลอง และข้อมูลแบบฟอร์ม |

## Mode And Storage Rules

- `Simulation mode` เริ่มด้วยข้อมูลตัวอย่างและเก็บการเปลี่ยนแปลงไว้เฉพาะระหว่างเปิดหน้า
- `โหมดกรอกและบันทึกข้อมูล` เก็บโปรไฟล์ ร่าง รายการใบสมัคร และตำแหน่งขั้นตอนจำลองใน PostgreSQL ของ Neon ผ่าน API ฝั่งเซิร์ฟเวอร์
- ตาราง `grant_users`, `grant_sessions` และ `grant_applications` แยกโปรไฟล์, session ที่ hash แล้ว และใบสมัครตามเจ้าของข้อมูล
- cookie `grant_plus_session` เป็น HttpOnly, SameSite=Lax, Secure เมื่อรัน production และหมดอายุใน 30 วัน ใช้เปิดทางให้กรอกอีเมลอย่างเดียวบนอุปกรณ์เดิม
- ปุ่ม “ออกจากระบบ” เก็บ cookie ไว้เพื่อความสะดวก; ปุ่ม “ลืมอุปกรณ์นี้” ลบ session ฝั่งฐานข้อมูลและล้าง cookie
- ระบบยังไม่มีการแบ่งสิทธิ์เจ้าหน้าที่, audit trail, account recovery, retention policy หรือ backup policy ที่ผ่านการรับรอง
- การเลือกไฟล์บันทึกเฉพาะชื่อไฟล์ในร่าง ไฟล์จริงยังไม่ถูกอัปโหลดหรือจัดเก็บ
- รหัสที่ขึ้นต้น `SIM-` และสถานะหลังส่งเป็นผลลัพธ์จำลอง ไม่ใช่เลขรับเรื่องจากหน่วยงาน

## Simulated Application Journey

1. กรอกและบันทึกข้อมูล — บันทึกในฐานข้อมูลจริงเฉพาะในโหมดกรอกข้อมูล
2. ส่งต่อแหล่งทุน — Simulation
3. ตรวจคุณสมบัติและเอกสาร — Simulation
4. ผู้ทรงคุณวุฒิประเมิน — Simulation
5. คณะกรรมการพิจารณา — Simulation
6. ประกาศผลและทำสัญญา — Simulation

## Readiness Calculation

- “ครบ” คิด 1 คะแนน “มีบางส่วน” คิด 0.5 คะแนน และ “ยังไม่พบ” คิด 0 คะแนน
- เปอร์เซ็นต์เป็นตัวชี้ความครบของข้อเสนอเทียบกับ template ที่เลือก ไม่ใช่โอกาสได้รับทุน
- รายการสาธิตมีแม่แบบ วช. Strategic Fund, NIA Open Innovation และ บพข. Full Proposal
- แหล่งอ้างอิงใน prototype ใช้หน้าคู่มือ/ประกาศของ NRIIS, NIA และ บพข.; ก่อนใช้งานจริงต้องให้เจ้าของทุนตรวจและอัปเดตรุ่นแม่แบบ
